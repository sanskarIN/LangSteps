# LangSteps v1.1.1 — Reliability & Learning Quality Update

LangSteps v1.1.1 is a maintenance update following the launch of Go, SQL, and C# learning paths in v1.1.0.

## What's improved

- **More reliable lessons:** Malformed links no longer break the new curriculum viewer. Lesson navigation works more predictably with browser history, and keyboard focus is easier to follow.
- **Copying code:** Better clipboard feedback and a select-to-copy fallback for browsers that block direct clipboard access.
- **No lost progress:** Existing Go, SQL and C# lesson completion records continue using their original localStorage keys.
- **Clearer examples:** Corrected C# record, model-binding and CORS examples; improved error handling in the Go HTTP tutorial.
- **Trustworthy leaderboards:** Removed fabricated offline/backend rankings and the optional API endpoint that accepted arbitrary XP values.
- **Safer API input handling:** Improved validation of quiz requests, including time and language checks.
- **Better offline behavior:** Refreshed the service worker to prioritize up-to-date pages while protecting cached lessons and other projects' caches.
- **Broader regression tests:** New automated tests for lesson navigation, storage, copying, API safeguards and PWA cache boundaries.

## Availability

Web learning paths and quizzes: https://sanskarin.github.io/LangSteps/

The website remains static on GitHub Pages. The optional ASP.NET Core API needs separate hosting; it does not offer hosted arbitrary-code execution. The leaderboard in the optional demo backend is not identity-verified.
