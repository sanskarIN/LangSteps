# LangSteps v1.4.0-rc.2 — Offline Reliability Preview

This is the second release candidate for v1.4.0. It is intended for testing, not a stable release. v1.3.0 remains the latest stable version.

## Changes since rc.1

- Explicit Offline Library downloads request live network responses rather than stale service-worker cache hits, so the controller can apply response validation before saving.
- Service-worker lookups are restricted to LangSteps-owned core, runtime and course-library caches. Unrelated same-origin caches are not used as offline fallbacks.
- Recently visited runtime pages take precedence over older core pages during network outages.
- The offline availability indicator consults LangSteps core/runtime caches, not all origin caches.
- Corrected missing local manifest references in legacy course entry pages.
- Added local asset reference checks and three service-worker regression tests; updated older test mocks to model named-cache lookups.

## Try the candidate

Open the [Offline Library](https://sanskarin.github.io/LangSteps/offline-library.html), save one course online, then test offline navigation and removal. Partial bundles may be resumed, and learner progress remains browser-local.

## Known limits

- Saved courses cover audited first-party files, not all linked pages, external code editors, fonts, APIs, or a complete offline execution environment.
- Browser storage may be evicted or denied. The optional ASP.NET Core backend is not hosted on GitHub Pages.
- Existing complete course snapshots are not automatically refreshed by this candidate. Use Remove and Save to request a new snapshot.
- Full-repository legacy HTML lint remediation is tracked in [issue #2](https://github.com/sanskarIN/LangSteps/issues/2); further offline work is tracked in [issue #11](https://github.com/sanskarIN/LangSteps/issues/11).
