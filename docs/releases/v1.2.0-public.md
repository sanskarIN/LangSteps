# LangSteps v1.2.0 — TypeScript Foundations & Learning Reliability

LangSteps v1.2.0 improves the existing ten learning paths with a more maintainable TypeScript-powered browser experience. The website continues to be free, static and usable without an account.

## LangSteps is now online

**Learn for free:** https://sanskarin.github.io/LangSteps/

The full public learning website is available online. Visitors can open any of the ten learning paths and the site's tools directly in their browsers. An accessible website announcement now appears on all 97 HTML pages, with a shared TypeScript dismiss controller and offline-cached assets. No sign-in is required for public lessons. Internet access provides the site; lessons and some tools can also work offline when previously cached.

Online availability does **not** imply remote code compilation, mandatory cloud storage, or deployment of the optional ASP.NET Core API.

## Highlights

- **Typed lesson experience:** Go, SQL and C# courses use a shared TypeScript viewer for navigation, lesson search and completion tracking. Existing learner mastery keys remain compatible with v1.1.x.
- **Better learning flow:** Previous/Next controls, browser history support, safer lesson deep links and improved keyboard focus.
- **Expanded Web API guide:** 15 searchable APIs, real examples, browser-permission notes and official MDN resources. Native disclosure cards can be read with JavaScript disabled.
- **Donation accessibility:** Shared typed modal controls with keyboard focus management and all three optional donation choices.
- **Offline improvements:** The GitHub Pages service worker is now authored in TypeScript and compiled to a static `sw.js`. Versioned caching preserves other projects' caches on the same Pages origin.
- **Mobile layout:** Fixed horizontal page overflow caused by long code samples.
- **Homepage reliability and safety:** Fixed previously malformed JavaScript in carousel and live preview; isolated the code preview inside a sandboxed iframe.
- **Quality checks:** Strict curriculum data validation, generated JavaScript parity verification, Node regressions and cross-browser Playwright smoke coverage.

## Scope and compatibility

- LangSteps remains a **static client-first website**. TypeScript sources are compiled to JavaScript; HTML remains necessary for semantic page structure, accessibility and non-JavaScript content.
- The optional ASP.NET Core service can be built separately; the GitHub Pages website does **not** deploy an ASP.NET Core server.
- Course snippets are educational examples and do **not** imply a secure remote execution sandbox.
- Stored lesson completion records continue using the historical `langsteps:v1.1.0:mastery:<slug>` prefix. No account or migration is needed.

## Verification

Release checks require clean TypeScript and ASP.NET Core builds, curriculum validation, Node tests, targeted HTML lint, and Chromium / Firefox / WebKit browser checks. Documented historical HTML cleanup remains tracked separately in issue #2.
