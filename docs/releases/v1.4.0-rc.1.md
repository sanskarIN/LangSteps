# LangSteps v1.4.0-rc.1 — Offline Readiness Preview

> **Pre-release candidate.** This is for early testing and feedback. The latest tagged stable release remains [v1.3.0](https://github.com/sanskarIN/LangSteps/releases/tag/v1.3.0).

## What changed since v1.3.0

- **Opt-in Offline Library:** save selected first-party files for each of ten paths, remove course bundles, cancel downloads, and resume verified partial downloads without redownloading their existing files.
- **Clearer offline status:** distinguish an entry page cached through a visit or worker preload from a complete opt-in course bundle; partial bundles display their local file counts.
- **Transparent external dependencies:** each course explains which features may still need internet, including hosted CodeMirror and React/Babel scripts, icon fonts, optional animations and network examples where relevant.
- **Storage resilience:** report approximate browser-origin storage, warn near capacity, provide actionable quota-error messages, and recover gracefully from unavailable CacheStorage.
- **Privacy:** browser-local, no login, no automatic curriculum download; course removal cannot delete unrelated applications' caches or learner mastery keys.
- **Reliability:** offline navigation reuse, temporary server error fallback for previously cached pages, scoped API exclusion and HTTP private/no-store safeguards.
- **Quality:** Node/TypeScript/HTML and ASP.NET Core checks plus Chromium, Firefox, and WebKit browser smoke and offline recovery tests.

## Try the preview

1. Open [LangSteps Offline Library](https://sanskarin.github.io/LangSteps/offline-library.html).
2. Select **Save** for one course while online.
3. Review the saved file status and that course's internet-dependent features.
4. Reopen the course without a connection. Static reading content from cached local files can work, but external tools may not.
5. Use **Remove** to delete that course's *explicit* library bundle. Other previously cached pages can remain, and browser storage can evict files independently.

## Important limitations

- **Not an offline code execution environment.** Externally hosted editors, fonts, APIs, translation and optional demonstrations still need internet, and some code examples remain explanatory rather than executable.
- Status reflects **saved first-party course bundle files and entry-page cache presence**, not a guarantee that the entire website, every lesson link or third-party functionality is offline.
- Browser storage is best effort and may be unavailable, full, evicted, or cleared. Reload to refresh the displayed state.
- GitHub Pages hosts static assets. The optional ASP.NET Core backend is **not** hosted by GitHub Pages.
- The remaining full-repository HTML lint baseline is tracked separately in [issue #2](https://github.com/sanskarIN/LangSteps/issues/2); the release workflow lints the release-facing pages.
