# LangSteps v1.1.0 — Go, SQL & C# Learning Paths

This release expands LangSteps to **10 learning paths**, introducing **45 new guided lessons** across Go, SQL, and C# / ASP.NET Core.

## New learning paths
- **Go Mastery — 15 lessons:** syntax, collections, methods, interfaces, errors, concurrency, channels, testing and HTTP services.
- **SQL Mastery — 15 lessons:** PostgreSQL-oriented SQL basics, joins, grouping, common table expressions, windows, transactions, indexing and secure parameters.
- **C# 13 / .NET 9 / ASP.NET Core — 15 lessons:** core language features, LINQ, async/await, dependency injection, Minimal APIs, model binding, security and testing.

Each new learning path offers lesson search, category filtering, practical examples, exercises, copyable code, deep links and **progress saved locally in your browser**.

## Improvements
- The homepage now links directly to all three new curricula.
- Frontend and server module catalogs are synchronized.
- PWA cache paths work under the `/LangSteps/` GitHub Pages project path and include the new curricula.
- Automated Node, TypeScript, ASP.NET Core and HTML lint checks cover the new release.
- API safeguards remove public feedback retrieval and restrict browser CORS origins.
- The optional backend no longer pretends code was executed when only simulated output was available.

## How to learn
Start at **https://sanskarin.github.io/LangSteps/** and choose Go, SQL or C# / ASP.NET Core.

The GitHub Pages website is static; the new examples are reading and practice material rather than hosted compilers. The optional .NET backend requires separate hosting. Secure remote code execution is not part of v1.1.0.
