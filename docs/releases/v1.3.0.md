# LangSteps v1.3.0 — Stable Release Verification

**Target:** v1.3.0
**Base:** v1.2.0 (published 2026-10-22)
**Website:** https://sanskarin.github.io/LangSteps/

## Implementation

1. src/sw.ts remains the authoritative TypeScript worker. Run npm run build:sw to generate checked-in sw.js.
2. docs/offline.html provides an accessible, no-JavaScript response for pages never downloaded for offline reading.
3. src/curriculum/offline-register.ts generates curriculum/offline-register.js and registers the scoped worker from Go, SQL and C# lesson pages.
4. The worker precaches essential assets. Runtime caching stores successful same-origin static resources (64 entries maximum). Navigations are network-first; offline, exact cached pages take priority over the fallback.
5. The worker ignores /api/ routes, non-GET requests and URLs outside /LangSteps/ while preserving other projects' caches.
6. No historical learner localStorage keys or lesson fragment IDs are modified.

## Release safeguards

- The old v1.2.0 publisher is retired.
- The v1.3.0 publisher only runs after a reviewed main-branch merge commit containing the exact text LangSteps v1.3.0 [publish].
- The publisher reruns full checks before creating v1.3.0. Failed validation must leave it unpublished.
- GitHub Pages deploys separately; verify the live website after publication.

## Future scope

The seven legacy curricula still have significant non-TypeScript browser code. Guided-course progress backup/restore, broader accessibility audits, historical HTML cleanup and full offline-download controls are future work. This release does not claim those are complete.
