# LangSteps v1.1.1 — Maintenance Release Preparation

**Target release:** `v1.1.1`  
**Status:** Prepared on `release/v1.1.1`; not tagged or published  
**Release type:** stable patch, following v1.1.0  
**Website:** https://sanskarin.github.io/LangSteps/  
**Repository:** https://github.com/sanskarIN/LangSteps

## Scope

This patch focuses on quality, privacy, trustworthy education content, and reliability without altering the v1.1.0 course structure or removing learner achievements.

### Curriculum viewer

- Recover gracefully from malformed URL fragments such as `#invalid%ZZ` and missing lesson IDs.
- Prevent double rendering when switching lessons and restore focus to the selected lesson heading during Back/Forward navigation.
- Make the example-copy feature usable when Clipboard API permissions are missing, selecting the code for manual copy instead.
- Provide a live-region status message for copy feedback and visible keyboard focus styles.
- Preserve focus on the same completion button when marking or undoing mastery; label single search results grammatically.
- **Preserve the `langsteps:v1.1.0:mastery:<slug>` localStorage keys** so existing completed lessons remain completed; this is intentional.

### Learning content

- Correct C# top-level statement ordering in record and API model-binding examples.
- Turn the CORS code snippet into a self-contained ASP.NET Core example.
- Handle Go HTTP server and JSON encoder errors in the tutorial code.
- Align the Go server catalog's category list with the seven categories in the published learning path.

### Optional ASP.NET Core API

- Reject quiz submissions with unknown languages, missing or empty answers, unknown question IDs, out-of-range choice indices, invalid elapsed time, or excessively long usernames.
- Return only question IDs, prompts, choices and display metadata from `GET /api/quiz/{language}`. Correct options and explanations appear only in the review returned by `POST /api/quiz/submit`; this intentionally changes the optional API question response contract.
- Remove the public API route that accepted arbitrary leaderboard XP totals.
- Remove fictional seeded leaderboard entries from the server and TypeScript offline fallback.
- Keep in mind the optional leaderboard is in-memory and **not identity-verified**. Authentication, anti-abuse controls and persistent backend storage remain separate work, not claims of this patch.

### PWA and release engineering

- Bump PWA cache to `langsteps-v1.1.1`.
- Prefer network responses for HTML navigations while retaining offline fallbacks.
- Limit fetch handling to the `/LangSteps/` service worker scope and avoid deleting other projects' caches on the shared Pages origin.
- Update package, TypeScript and ASP.NET Core version metadata.
- Retire the one-time workflow that published v1.1.0. It should not run on every later deployment.
- Add automated viewer behavior tests, service-worker tests, curriculum checks and API safety assertions.
- Run `tests/api-smoke.sh` against a locally started ASP.NET Core server in CI to verify question privacy, valid scoring and invalid submissions.

## Known boundaries

LangSteps GitHub Pages is a static site. The optional ASP.NET Core API is not deployed by GitHub Pages, and v1.1.1 does not introduce a secure arbitrary code execution environment. The older HTML pages still have a separately tracked formatting/lint backlog (issue #2). A passing build does not, by itself, prove every existing lesson's content is complete or every old browser page is error-free.
