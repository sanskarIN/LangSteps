# LangSteps v1.3.0 — More Reliable Offline Learning

LangSteps remains a free, open-source programming learning site with ten public paths, no account requirement, and browser-local learning progress.

Website: https://sanskarin.github.io/LangSteps/

## Highlights

- **Read visited lessons offline.** The TypeScript-based service worker now saves successful visits to same-origin HTML pages, JavaScript, stylesheets and other small static resources on demand. This extends beyond the previously precached Go, SQL and C# pages. Previously downloaded resources may be removed by browser storage management.
- **Clear offline feedback.** Unvisited pages no longer silently show the homepage when the network is unavailable. An accessible fallback explains that the requested lesson is not yet downloaded.
- **Start from course links.** Direct visits to Go, SQL or C# lesson pages can register the scoped service worker without first opening the homepage.
- **Bounded cache and isolation.** A 64-entry runtime cache avoids uncontrolled accumulation, while cache upgrades only remove keys belonging to LangSteps. API requests, POST requests and cross-origin/cross-project traffic are never intercepted.
- **Safer cache admission.** Error responses and responses with no-store directives are excluded from runtime storage.
- **Regression coverage.** New worker tests cover upgrade isolation, visited and unvisited pages, on-demand resources, invalid responses and eviction. Cross-browser scenarios include offline course reloads and missing-content behavior.
- **Version consistency.** Package, TypeScript health fallback and optional ASP.NET Core API metadata are aligned with v1.3.0.

## Important limitations

- The entire ten-path curriculum is not downloaded during installation. Open a page while online before relying on it offline; some external content and tools still need internet access. The browser may evict saved files.
- GitHub Pages remains static. The optional ASP.NET Core backend is not hosted by GitHub Pages, and LangSteps does not claim to execute every course's code remotely.
- Lesson progress remains local to the browser and retains the existing langsteps:v1.1.0:mastery:<slug> storage keys; this release does not delete or migrate learner records.
- No sign-in or tracking is introduced.

## Verification

The release workflow must pass Node regressions, curriculum validation, TypeScript builds and generated-code drift checks, targeted HTML lint, optional ASP.NET Core build and API smoke tests, and Playwright smoke tests in Chromium, Firefox and WebKit before it can publish the stable v1.3.0 tag.
