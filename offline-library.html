Before you download

Saving a course captures its listed local page, scripts and styles—not a guaranteed fully offline code editor. Some courses use external libraries, fonts or tools that still need internet. Saved data may be evicted when browser storage is full or cleared. Existing progress is not changed.

“Remove” deletes only that course's Offline Library download. Files previously visited or included in LangSteps' basic offline cache may remain available.
